## Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas** e atuo profissionalmente com **provisionamento de redes**.

No dia a dia, trabalho com configuração e validação de equipamentos de rede, VLANs, interfaces, banda, SFP/potência, BGP e documentação técnica. Paralelamente, desenvolvo projetos para ampliar minha experiência em **desenvolvimento de software**, com foco em back-end, aplicações web e mobile.

Atualmente estudo principalmente **Java, JavaScript e React Native**, além de aprofundar meus conhecimentos em redes.
